# Contributing

Thanks for your interest. Every change is reviewed by the maintainers, and pull requests
that fall outside the project's scope will be closed. Please open an issue to discuss a
change before you spend time on it.

**Welcome:** bug fixes, clearer documentation, and small, focused improvements with a
short note on how you tested them.

**Not accepted:** secrets or real `.env` files, large binary files, new features or
dependencies the project doesn't need, GitHub Actions workflows, and unrelated
refactors or reformatting.

Found a security problem? See [SECURITY.md](SECURITY.md) and report it privately.
